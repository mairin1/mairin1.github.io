Hush - Creating Video Games Final Project

  • Play our musical-medieval-side-scroller here!

    This class was full of programmers (as expected), so I took the opportunity to volunteer to work on animation assets for my team. See "Keytar Hit" and "Player Takes Damage" to the left. I did end up needing to do a fair bit of coding in C# and specifying in Unity Engine (setting up animations for a single entity requires drawing out a finite state machine in Unity's UI), but the design portion ended up being the most interesting. The colors and art style set a vibe, sure, but I also had to figure out what feedback I could give the player through the visual state of the game that would make the experience more immersive/enjoyable/etc.
